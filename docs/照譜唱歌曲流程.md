# 照譜唱的歌曲：歌聲合成＋程式編曲流程

> 適用：使用者給了**譜和歌詞**，要求「旋律一個音都不能改、照詞唱」的歌——校歌、兒歌、既有歌曲改編（換曲風、換速度）。
> 原創新歌（只有歌詞、旋律交給 AI 寫）不走這裡，照 `production-sop.md` 第三節用 Music 3。
> 第一次走完這條路的作品：`output/歌曲MV/沙鹿國中校歌/`（2026-10-28，輕快改編版）。

## 為什麼不用 ComfyUI

ComfyUI 的音樂模型（Music 3、YuE2、ACE-Step）都是**把譜或錄音當參考重新創作**，做不到逐音照譜：
旋律會跑、後段會錯位、中文常被唱成粵語，生成的伴奏速度也會飄。實測細節在 `comfyui` 技能的
`models/yue2.md`、`models/ace-step.md`。所以這類歌：**人聲用歌聲合成軟體照 MIDI 唱，伴奏用程式照同一份譜寫 MIDI**。

## 整條流程

```
譜（圖片／PDF）──人工打譜──▶ song.json ──score.py──▶ 試聽 wav、MusicXML、人聲 MIDI
                                │                          │（使用者確認旋律）
                                ├──chords.py──▶ 和弦譜＋試聽（使用者確認和弦）
                                │   ▲ compare.py（拿原錄音核對旋律、推和弦）
                                └──arrange.py──▶ 伴奏 MIDI ──render.py（FluidSynth）──▶ 伴奏 wav
人聲 MIDI ──OpenUtau（使用者操作）──▶ 人聲 wav ─────────────────mix.py──▶ 混音 wav ──▶ mp3
```

程式都在 `tools/sing/`（只用 Python 標準函式庫＋numpy，另需 ffmpeg），每支的用法寫在檔頭。
作品資料夾只放 `work/譜/song.json` 與產出，不再各自複製一份腳本。

## 二、步驟

### 1. 打譜成 song.json（最花工夫，也最重要）

在作品的 `work/譜/` 建 `song.json`，格式寫在 `tools/sing/song.py` 檔頭。要點：

- **照譜面打，不要照錄音抓**。程式抓音高（`work/旋律分析/` 那種）只能當草稿，節奏常對不上。
- **先看清楚調號**：校歌那次第一眼讀成 G 大調，其實是 D 大調（兩個升記號）。音名照譜面寫，`key` 填譜面的調。
- **錄音常跟譜不同調**（校歌的錄音比譜低一個全音）。資料照譜面存，輸出時用 `--key` 移調，不要改資料。
- 長度單位是十六分音符（四分＝4、附點八分＝3）；程式會檢查每小節滿 16，弱起與最後一小節可不滿。
- 一字多音（圓滑線）：同一個字列多個音。休止：`["", "", [["r", 4]]]`。
- 拼音**以台灣讀音為準**，帶聲調數字（輕聲 5）：例如「樸」是 `pu2` 不是 `piao2`。破音字逐一列給使用者核對。
- `chords` 照譜面調寫，每小節前後半各一個，`null`＝延續前半；支援 `C`、`Am`、`G7`、`Fmaj7`、`Bdim`、`Csus4`、`C/E`。
- `arrange.chorus_bar`：副歌從第幾小節開始；`brass_hits`：哪些小節的旋律要加銅管重音（像「奮起兮奮起」）。

### 2. 核對旋律與和弦（使用者試聽確認）

```bash
python tools/sing/score.py <song.json> --key C --bpm 110
python tools/sing/compare.py <song.json> orig.wav --key C --bpm 110.1 --offset 0.265
python tools/sing/chords.py <song.json> --key C --bpm 110
```

- `score.py` 出 MusicXML、`_漢字.mid`／`_拼音.mid`（延續記號 `-`）、`_OpenUtau.mid`（延續記號 `+`）、`_試聽.wav`。
- `compare.py` 出「左原唱、右手打譜」的對照 wav（核對有沒有打錯）與每半小節的和弦建議（人聲干擾大，只供參考）。
- `chords.py` 出和弦譜 md 與「旋律＋和弦」試聽 wav。**旋律、和弦都要使用者說對了才往下做。**

### 3. 編曲（改曲風只動這一步，旋律不動）

```bash
python tools/sing/arrange.py <song.json> --key C --bpm 128 --intro-bars 4 --tag 輕快版
```

- 兩種編制，用 `--style` 選（要別的曲風，在 `arrange.py` 再加一種，不要複製一份改）：
  - `band`（預設，`--tag 輕快版`）：鼓、指彈貝斯、鋼琴、清音電吉他刷奏、銅管、鐘琴。用 GeneralUser GS 算，使用者覺得「質感較 LOW」。
  - `march`（`--tag 管弦進行曲版`）：弦樂、大提琴、撥弦、長笛、單簧管、法國號、小號、長號、大號、定音鼓、小鼓／大鼓／鈸、鐘琴、豎琴；
    低音打一三拍、法國號（副歌加長號）打二四拍，弦樂鋪底＋和弦內音的對位線，副歌長笛高八度疊旋律，力度與起音加微小隨機、弦樂用 CC11 漸強。
    沒有 numpy 預覽，直接 `render.py --sf MuseScore_General --hall --gain 0.45` 算（`--hall` 開 FluidSynth 大廳殘響；gain 0.6 會削峰）。
  - 兩種都是：前奏用最後 N 小節的旋律，接一個屬七＋鼓過門的小節，主歌輕、副歌全團、尾奏主和弦。
- `band` 先聽 `伴奏預覽_*.wav`（numpy 簡單音色，只聽結構），使用者同意方向後再算真樂器：

```bash
python tools/sing/render.py 伴奏_輕快版_128BPM.mid 伴奏_輕快版_128BPM.wav
```

  `_含旋律導引.mid` 多一軌長笛奏旋律，算出來給使用者在人聲做好之前試聽。

### 4. 人聲：OpenUtau（使用者操作，agent 只能出 MIDI 與說明步驟）

```bash
python tools/sing/score.py <song.json> --key C --bpm 128 --intro-bars 4
```

`--bpm`、`--intro-bars` 要跟 `arrange.py` 一樣，第一個字才會對上伴奏。請使用者在 OpenUtau：

1. 匯入 `<stem>_C調_128BPM_前奏4小節_OpenUtau.mid`，歌手選绮萱（音素器 `DiffSingerChinesePhonemizer` 是預設）。
2. **去機器人感**：在鋼琴捲簾 `Ctrl+A` 全選音符 → 在**音符上**按右鍵（不是段落上）→「音符」→「載入已算繪的音高曲線」（`Ctrl+R`）。
   剛匯入時音高是平直的階梯，聽起來像機器人是正常的；長音可再開「顫音」。
3. 匯出 WAV（預設輸出到 MIDI 旁的 `Export/`），存好專案 `.ustx`。

拿到人聲後，複製到 `work/audio/人聲_<歌手>_<BPM>BPM.wav`，量第一個字的時間跟 `arrange.py` 印的秒數比對。

### 5. 混音

```bash
python tools/sing/mix.py 人聲.wav 伴奏.wav 混音v1.wav [--vocal-db 2] [--reverb 0.18]
ffmpeg -i 混音v1.wav -map_metadata -1 -b:a 192k 混音v1.mp3
```

人聲高通 100Hz、輕壓縮、殘響，人聲比伴奏大 2dB，母帶峰值 -1dBFS。**由使用者試聽**決定要不要調 `--vocal-db`、`--reverb`。

### 6. 定案與發布

照 `production-sop.md` 第一節移到作品資料夾最上層、第四節清 metadata；`發布資訊.md` 的署名要寫：
原作詞、原作曲者與「改編」字樣，以及聲庫條款要求的「AI 合成」「绮萱」「DiffSinger」。

## 三、踩過的坑

- 校歌的譜 81 字、97 個音（多出的 16 個音都是一字多音）；YuE2 自動轉譜就是在這裡錯位。歌聲合成的 MIDI 一定要把一字多音的後續音標成延續記號，不能每個音都放字。
- OpenUtau 的延續記號是 `+`，Synthesizer V 等是 `-`；`score.py` 兩種都輸出。
- OpenUtau 沒有指令列算圖，人聲這一步一定要使用者在介面裡做。
- FluidSynth 會把殘響算得很長（校歌伴奏 58 秒，輸出 88 秒），`render.py` 依 MIDI 長度剪掉並淡出。
- 生成式伴奏（ComfyUI）跟照譜的人聲對不齊，伴奏一律用 MIDI。
- 32MB 的 GM 音色庫（GeneralUser GS）配力度固定的編曲，聽起來「質感較 LOW」；管弦樂改用 MuseScore General＋力度微調＋CC11＋大廳殘響。免費音色庫仍到不了商業管弦音源的水準。
- 管弦樂動態大，混音後整體響度比樂團版低約 3dB（-17.8 對 -14.3 dBFS RMS），是峰值卡在尾奏全團的關係。
